Changes compared to EEP in MEDC17:
- Master layout configuration is ignored from the Eep adapter 
  -> all configuration tags on master block level are ignored and has no effect.
- Security level 3 is mapped to security level 2 (Only security level 1 or 2 are supported) (XML tag <EEP_BLOCK_SECURITY_LEVEL>)
- History is always enabled and could not be deactivated (configuration is ignored) (XML tag <EEP_BLOCK_INITS_HISTORY>)
- Error healing in postdrive is not supported
- Reinitialization is not supported
